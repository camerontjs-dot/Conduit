A typed request acknowledgment and an observed effect are separate fields. Retain the first failure; a changed apparatus or candidate gets a separate identity.

No global native PASS, fresh independence, operator installation, provider/account action, hosted entitlement or source-transmission approval is established by this preparation. The JSON matrix carries exact source links and per-case receipt fields.
